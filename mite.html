OVERVIEW & ARCHITECTURE

An engine built with constraints in mind.

Mite demonstrates that high playing strength does not require hundreds of thousands of lines of code. By combining efficient algorithmic density with strict memory constraints, it provides a tournament-ready engine in a single C source file.

Developed by Viraj Ravani, Mite was conceived as an engineering study in minimalism: how much chess intelligence can be packed into a single C file without relying on external dependencies or compromising search depth?

The engine operates strictly through the Universal Chess Interface (UCI) standard protocol. Rather than embedding a proprietary user interface, Mite connects directly over standard input and output (stdin / stdout) to established chess GUIs like Arena, Cutechess, and BanksiaGUI, as well as automated tournament managers.

“Every heuristic in Mite is evaluated for its algorithmic density: maximum tactical value per byte of compiled code.”

The complete engine source code is contained in src/Mite.c, measuring approximately 19.7 KB across ~409 lines. When compiled with optimization, it produces a standalone Windows binary of approximately 115 KB requiring zero runtime DLLs, and a ~60 KB WebAssembly module for instant in-browser play.

INTEGRATION & USAGE

How to play and test Mite.

Mite is a pure UCI engine that communicates over standard input and output. It does not provide an internal GUI, but integrates seamlessly into all major chess interfaces.

Play Instantly in Your Browser

01.
Open the official Hugging Face Space in any desktop or mobile browser.
02.
Select your preferred time control: Bullet (1+0, 1+1), Blitz (3+0, 3+2, 5+0, 5+3), or Rapid (10+0, 15+10).
03.
Choose your side (White, Black, or Random) and start moving pieces on the board. The engine runs locally on your device via WebAssembly.

Configuring Mite in Arena Chess GUI

01.
Download Mite.exe from the repository.
02.
In Arena, navigate to the top menu: Engines → Install New Engine...
03.
Browse to and select Mite.exe. When prompted for engine protocol, select UCI.
04.
Start a new match or game against Mite under your desired time control.

Configuring Mite in Cutechess

01.
Open Cutechess and navigate to Tools → Settings → Engines.
02.
Click the + button to add a new engine, then browse to bin/Mite.exe.
03.
Cutechess will query the engine over UCI and automatically populate its name and author details.

Automated Match Testing via Cutechess-CLI

Run automated tournament matches against reference engines with reproducible PGN output:

Bash / Command Line 
cutechess-cli -engine cmd=bin/Mite.exe name=Mite proto=uci \
              -engine cmd=opponent.exe proto=uci \
              -each tc=10+0.1 -rounds 200 -repeat -recover \
              -pgnout match.pgn

Direct UCI Terminal Interface

Running Mite.exe in a terminal opens standard UCI listener mode. You can inspect responses directly:

UCI Protocol Commands 
# Launch engine
bin/Mite.exe

# Handshake & probe
uci
isready

# Setup position and calculate
position startpos moves e2e4 e7e5
go depth 8

Building from Source

Mite compiles with any standard C compiler without external dependencies:

Compiler Commands 
# Using Makefile (MinGW / POSIX)
mingw32-make

# GCC (MinGW / Linux)
gcc -O3 -fomit-frame-pointer src/Mite.c -o bin/Mite.exe

# Clang / LLVM
clang -O3 -flto src/Mite.c -o bin/Mite.exe

# MSVC (Visual C++)
cl /O2 /Oi /Ot /GS- src\Mite.c /Fe:bin\Mite.exe
